Watch the rollout:

  kubectl -n {{ .Release.Namespace }} rollout status deployment/telemetry-api
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}

Check readiness. A pod that is running but not ready cannot reach a dependency;
the response body names which one:

  kubectl -n {{ .Release.Namespace }} port-forward svc/telemetry-api 8080:{{ (index .Values.workloads "telemetry-api").service.port }}
  curl -s localhost:8080/ready | jq

{{- if .Values.ingress.enabled }}

  kubectl -n {{ .Release.Namespace }} get ingress {{ include "oat.fullname" . }}
{{- else }}

No ingress was created. Reach the dashboard with a port-forward:

  kubectl -n {{ .Release.Namespace }} port-forward svc/web 8000:{{ .Values.workloads.web.service.port }}
{{- end }}

Prove the whole pipeline works — ingest, Kafka, the stream processor,
PostgreSQL, alerting, RabbitMQ, retry and dead-lettering:

  make smoke API_URL=http://localhost:8080
